Bank Management Project with C++

The main purpose of this project is to create and record multiple bank accounts and to facilitate money transfers between these bank accounts. Another important feature is the ability to store account information in a .txt file so that even when the program is restarted, it can still use the account information. As seen in the screenshots below, whether two accounts are newly created or previously created, the program can recognize the account information and present it to the user. Unfortunately, I am aware that the code is poorly written because this project was a school assignment, and at that time, I was just starting to learn C++ and was not fully proficient in OOP.
